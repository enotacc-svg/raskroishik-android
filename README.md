# Раскройщик для Android

Нативная Android-оболочка для автономного приложения раскроя рулонных материалов. Размер рулона задаётся пользователем, размеры деталей сгруппированы по оконным блокам, приложение рассчитывает схему и расход материала.

**Что меняется по сравнению с веб-версией:** сохранение схемы PNG в Галерею телефона и отправка файла через системное меню Android (включая Gmail, если установлен). Адрес получателя при указании передаётся в email-приложение как подсказка. Отправка письма требует подтверждения пользователя. Доступ к интернету для раскроя не нужен.

## Сборка без Android Studio — GitHub Actions

1. Создайте **пустой GitHub-репозиторий** (например, `raskroishik-android`).
2. Разархивируйте этот ZIP на компьютере. В репозитории нажмите **Add file → Upload files** и загрузите **содержимое** папки `Raskroishik_APK_Project`, сохраняя структуру подпапок, включая скрытую `.github/workflows/build-apk.yml`. На компьютере можно выделить сразу все файлы и папки и перетащить их в окно браузера.
3. Выберите **Commit changes** в ветку `main`. Если рабочая папка `.github` не загрузилась через веб-интерфейс, создайте файл `.github/workflows/build-apk.yml` в репозитории вручную из приложенного файла.
4. Откройте вкладку **Actions → Build APK → Run workflow** (либо дождитесь запуска от push в ветку `main`). Если GitHub предложит включить Actions, включите.
5. После **успешного** выполнения откройте завершённый запуск, внизу найдите **Artifacts → Raskroishik-Android-APK**. Скачайте архив, распакуйте — внутри будет `app-debug.apk`.
6. Перенесите APK на Android-телефон и откройте. При необходимости разрешите установку из выбранного приложения. Это тестовая debug-сборка для личного использования, не приложение из Google Play.

Важно: наличие проекта **не означает**, что APK был уже собран или протестирован на реальном Android-устройстве. Для первой сборки необходимы интернет и доступ к GitHub Actions (это выполняется на серверах GitHub).

## Локальная сборка

Откройте папку в Android Studio (JDK 17; AGP 8.7.3; compileSdk 35), дождитесь синхронизации Gradle, выберите `Build → Build Bundle(s) / APK(s) → Build APK(s)`. Результат `app/build/outputs/apk/debug/app-debug.apk`.

## Особенности отправки

При нажатии **Отправить по email** приложение создаёт PNG в Галерее (Pictures/Раскройщик) и открывает меню «Поделиться». Для отправки именно письмом нужно выбрать Gmail/Outlook/другую почту и подтвердить отправку.

Поддерживаются Android 10 и новее (API 29+). Разрешения на доступ ко всем файлам и к интернету не требуются.
