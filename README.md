# Раскройщик 2.4.1 · МОЕМ ВСЁ 360

Android-приложение для раскроя рулонной плёнки, ручной резки, истории схем и учёта остатков.

## Возможности
- Нижняя панель: Раскрой / История / Рулоны.
- Режимы: удобство ручной резки и экономия материала.
- Склад рулонов: ввод ширины, длины, остатка; выбор рулона в калькуляторе.
- Списание происходит только после подтверждения; операцию можно отменить.
- История раскроек, PNG-схема, отправка через почтовое приложение.
- Данные на устройстве в локальном хранилище и Android SharedPreferences.

## Сборка APK
Во вкладке Actions откройте Build APK. При изменениях в main процесс запускается автоматически. После успешного завершения скачайте Artifacts → Raskroishik-Android-APK → app-debug.apk.

Не удаляйте старую версию перед обновлением: сохранённые данные могут быть потеряны. Установка поверх существующего приложения возможна, если совпадает подпись APK.

Файл версии: app/build.gradle (versionCode=7, versionName=2.4.1). Собирается Gradle 8.9, JDK 17 и Android SDK 35.
