01. Размер рулона

Сантиметры

Если длина не указана, программа подберёт необходимую длину рулона. Если указана — рассчитает количество рулонов.

02. Детали для раскроя

Размеры вводятся в сантиметрах. Можно добавить несколько оконных блоков и любое количество деталей (до 300 штук в расчёте).

03. Готовая схема

На Android нажми «Отправить по email» → выбери Gmail или другую почту. PNG прикрепится к письму. Если указан адрес, приложение попытается скопировать его для вставки в поле «Кому».

Схема показывает фактическое размещение деталей. Для рулонов с заданной длиной неиспользованный остаток указывается в расчёте, но не растягивает изображение.

Для установки на Android открой опубликованную по HTTPS версию в Chrome, затем в меню ⋮ выбери Установить приложение или Добавить на главный экран.
