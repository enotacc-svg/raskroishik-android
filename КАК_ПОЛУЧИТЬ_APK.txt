КАК ПОЛУЧИТЬ APK (без Android Studio)

1. Распакуйте архив с проектом на компьютер.
2. Создайте бесплатный репозиторий на github.com с названием raskroishik-android.
3. Загрузите в репозиторий ВСЁ содержимое распакованной папки, включая скрытую папку .github.
4. На GitHub откройте вкладку Actions → Build APK → Run workflow.
5. Когда сборка завершится с зелёной галочкой, скачайте артефакт Raskroishik-Android-APK.
6. Распакуйте скачанное: внутри лежит установочный файл app-debug.apk.
7. Отправьте APK Максу — он сможет установить его на свой Android.

При первом открытии Android может попросить разрешить установку приложений из этого источника.
Этот ZIP — исходники, а не готовый APK. На вашем телефоне приложение не запускается из ZIP.

Функции: настраиваемая ширина/длина рулона; зазор; поворот деталей; несколько оконных блоков; PNG схема; сохранение изображения в Галерею; отправка PNG через Gmail/почту; работа офлайн.

Проект подготовлен для сборки с Android 10 и новее. Готовый APK в текущем окружении пока не собирался и на устройстве не проверялся.
